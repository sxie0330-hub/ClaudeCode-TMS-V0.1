# 提醒与每日邮件

## 系统会提醒什么

所有提醒都在 **我的工作台 → 今日待办** 里。每个人可以在 **规则设置** 中逐条开关提醒，修改提前天数、范围（我的项目 / 全部）和级别。和到港、项目节点相关的规则：

| 规则 | 默认 | 什么时候出现 |
|---|---|---|
| 柜子即将到港 / 已过 ETA 未确认到港 | ETA 前 3 天 | Load 状态是"待到港"，所属提单（MBL）的 ETA 在 3 天内。会提示还缺车队或 LFD。过了 ETA 还没填实际到港（ATA）时，升级为紧急。 |
| 项目节点临近或已过期未完成 | 前 3 天 | 项目里程碑（例如"船到港 ETA"）的计划日期快到了，或者已经过了却还没填完成日期。 |
| LFD 临近，柜子还没提 | 前 2 天 | 已有 |
| 即将开始，还没指派承运商 | 前 5 天 | 已有 |

ETA 和 ATA 从哪里来：
- **AI 新建项目时**：如果邮件里有 ETA，会同时写进项目里程碑和这个柜子的提单。
- **之后的更新邮件**：例如船公司改了 ETA，或者通知已卸船，用 AI 识别即可更新 ETA / ATA。填了 ATA 以后，Load 会自动从"待到港"变成"已到港"。
- **手动**：在 Load 页面点"编辑提单"。

## 每日邮件

每个工作日早上 7:00（太平洋时间，周一到周六），系统会把每个人当天的今日待办发到他的公司邮箱：
- 内容和网页上看到的完全一样，同样遵守每个人的规则设置和金额可见权限。
- 当天没有待办的人不会收到邮件。
- 每个人可以在 **今日待办 → 规则设置** 最上面关掉邮件，或者点 **现在发一封给我看看** 测试。

### 开通（管理员做一次）

**第一步：准备一个发件邮箱和它的"应用专用密码"**

1. 建议用一个专门的 Workspace 邮箱，例如 `tms@advtransolution.com`；用你自己的邮箱也可以。
2. 用这个邮箱登录 <https://myaccount.google.com/security>，打开 **两步验证**。如果找不到这个选项，需要 Workspace 管理员先在 admin.google.com → 安全 → 身份验证 里允许两步验证。
3. 打开 <https://myaccount.google.com/apppasswords>，名称填 `TMS`，点创建，复制生成的 16 位密码。

**第二步：在 Cloud Shell 里运行**
```bash
cd ~/tms && git pull && bash scripts/enable_email.sh
```
按提示输入发件邮箱和刚才的 16 位密码。脚本会依次完成下面这些事：
- 把密码存进 Secret Manager；
- 部署新版本；
- 创建每天 7:00 的定时任务（Cloud Scheduler）；
- 立刻试发一次。

### 费用

- **Cloud Scheduler**：每个结算账号每月有 3 个免费任务，这里只用 1 个。
- **邮件**：用公司邮箱发送，不额外收费。

### 修改发送时间
```bash
SCHEDULE="30 6 * * 1-5" bash scripts/enable_email.sh   # 例：周一到周五 6:30
```
