# 提醒

## 系统会提醒什么

所有提醒都在 **我的工作台 → 今日待办** 里。每个人可以在 **规则设置** 中逐条开关提醒，修改提前天数、范围（我的项目 / 全部）和级别。和到港、项目节点相关的规则：

| 规则 | 默认 | 什么时候出现 |
|---|---|---|
| 柜子即将到港 / 已过 ETA 未确认到港 | ETA 前 3 天 | Load 状态是"待到港"，所属提单（MBL）的 ETA 在 3 天内。会提示还缺车队或 LFD。过了 ETA 还没填实际到港（ATA）时，升级为紧急。 |
| 项目节点临近或已过期未完成 | 前 3 天 | 项目里程碑（例如"船到港 ETA"）的计划日期快到了，或者已经过了却还没填完成日期。 |
| LFD 临近，柜子还没提 | 前 2 天 | 已有 |
| 即将开始，还没指派承运商 | 前 5 天 | 已有 |

ETA 和 ATA 从哪里来：
- **AI 新建项目时**：如果邮件里有 ETA，会同时写进项目里程碑和这个柜子的提单。
- **之后的更新邮件**：例如船公司改了 ETA，或者通知已卸船，用 AI 识别即可更新 ETA / ATA。填了 ATA 以后，Load 会自动从"待到港"变成"已到港"。
- **手动**：在 Load 页面点"编辑提单"。
