# 邮箱自动扫描

每天傍晚 5:00（洛杉矶时间，夏令时 PDT 和冬令时 PST 都一样），TMS 会只读地查看已连接的 Gmail 邮箱，找出和**在执行项目**有关的新邮件，用 AI 识别出更新，放进负责人的 **今日待办 → AI 发现 X 项更新待确认**。点开核对后写入，和手动粘贴识别的流程一样。

## 读哪些邮件、不读哪些

- 用在执行项目里所有 Load 的 **柜号、MBL 号、承运商单号** 搜索上次扫描之后的新邮件；第一次扫描往回看 3 天。
- **没有提到这些单号的邮件不会被打开**，也不会发给 AI。
- 同一个项目当天的邮件合并成**一次** AI 识别。没有新邮件的项目不会调用 AI。
- 读过的邮件会记下来，不会重复读。
- 识别结果没有任何变化的，不会出现在今日待办里。
- 只能连接**自己的**邮箱；权限是只读的“查看您的电子邮件”，不能发信、删信。连接的授权加密保存。
- 在 **AI 识别 → 邮箱自动扫描** 页面可以随时断开，断开时会同时撤销 Google 授权。

## 开通（管理员做一次）

1. 在 Cloud Shell 运行：
   ```bash
   cd ~/tms && git pull && bash scripts/enable_mail_scan.sh
   ```
   脚本会启用 Gmail API、部署新版本，并设置每天 5:00pm 的定时任务。
2. 按脚本最后的提示，在 **Google Auth Platform → Clients → TMS 客户端 → Authorized redirect URIs** 加一条：
   `https://tms-668605433770.us-central1.run.app/mail/callback/`
3. 等几分钟，打开 TMS → **AI 识别 → 邮箱自动扫描**，点 **连接我的邮箱**，按 Google 提示允许。
4. 想马上试，点 **现在扫描一次**。

## 费用

- **Gmail API**：不收费。
- **Gemini**：每个有新邮件的项目每天调用一次，估计每次 1 美分以内。
- **Cloud Scheduler**：用 1 个定时任务，在每个结算账号每月 3 个免费任务的额度内。

## 常见问题

- **“邮箱授权已失效，请重新连接邮箱”**：改了 Google 密码、在 Google 账号里移除了 TMS 的权限，或者 6 个月没用，授权都会失效。到页面上重新连接即可。
- **Google 授权页提示 redirect_uri_mismatch**：第 2 步的地址没加，或者还没生效。
- **改扫描时间**：`SCHEDULE="0 16 * * 1-5" bash scripts/enable_mail_scan.sh`（例：周一到周五 4:00pm）。
