# New Jersey — Oversize/Overweight Permit Regulations

采集：oversizeloadassistant.com（Super Search Engine，会员），2026-10-16。
提醒：网站为资料整理库，实际出车前请以 NJDOT 官方最新规定为准。

## 0. 基本信息（General Information）

- 主管机构：NJDOT, 1035 Parkway Ave, Trenton, NJ 08625
- 电话：609-963-2085 / 传真：609-530-5270
- 邮箱：superload.permits@dot.nj.gov
- 许可有效期：5 天；办公时间：7:30am–4:00pm（东部时间）

## 1. Legal Dimensions & Weights（法定尺寸重量）

| 项目 | 标准 |
|---|---|
| 法定宽 | 8'0"（全路网）/ 8'6"（指定干线） |
| 法定高 | 13'6" |
| 法定长 | 见注 2 |
| 挂车长 | 53'0" |
| 总重 | 80,000 磅 |
| 单轴 | 22,400 磅 |
| 双轴 | 34,000 磅 |
| 三轴 | 56,400 磅 |

- 注 2（长度）：单车 40'0"；不可拆货单车 50'0"；车头/半挂 62'0"；挂车 48'0"；半挂 53'0"（kingpin ≤41'0"）

## 2. Overweight Allowances（超重许可上限）

- 单/双/三/四轴：按轴间距逐案批；总重无固定上限
- 轴重按 800 磅/英寸胎宽计算；注册总重 80,000 磅

## 3. Permit Fees（许可费用）

| 项目 | 费用 |
|---|---|
| 单次（法定重量） | $10.00 + 超尺寸费 + $12.00 交易费 + 5% 服务费 |
| 超重单次 | $10.00 + 超重费 + $12.00 + 5% |
| Superload | 同上 |
| 年票（海运柜） | $100 + $12 + 5% = $117.60/证 |
| 年票（Code 23 重型设备） | $209.50 |
| 年票（Code 23 挂车） | $12.60 |

## 4. Annuals（年票）

- 有：海运柜；Code 23 重型设备/机械超尺寸超重；Code 23 挂车

## 5. Curfews（限行）

- 无 curfew

## 6. Drop/Lift Axles（升降轴）

- 超重时必须放下：否

## 7. Pilot Car Requirements（护送车要求）

- 宽 >14'0"：1 辆；宽 >16'0"：2 辆
- 高 >14'0"：见电线规定；高 >16'0"：勘测要求（见第 11 节）
- 长 >100'0"：1 辆；长 >120'0"：2 辆
- 夜间获批时可能加车

## 8. Pilot Car Equipment & Certification（护送车设备）

- 认证：不需要
- 灯：头灯+尾灯全程开
- 牌："WIDE LOAD"/"OVERSIZE LOAD"，5'×1'，字 10"，黑字黄底
- 旗：2 面 18" 红方旗，前车前角、后车后角
- 其他：双向电台

## 9. Police Dimensions（警车开道）

- 网站未列具体尺寸；州警电话 608-882-2000（页面原文，疑应为 609 区号）

## 10. Superload Dims（特大件标准）

- 总重 150,000 磅起（>150,000 磅桥梁审查 2–5 天）
- 纯超尺寸不算 superload；>14'0" 宽/高建议勘测（14'6" 以内无勘测也可发证，高不保证）

## 11. Survey（路线勘测）

- 宽 >16'0"：勘测；高 ≥14'6"：必须勘测（高 ≥14'0" 强烈建议）
- 无固定净空标准；有效期 21 天；要求与加州类似（冲突点+让行区域，申请公司负责联系电力/信号灯业主）

## 12. Night & Weekends（夜间/周末）

- 周末（日出–日落）：宽/高/长/重/悬不限
- 夜间：仅超重车可走（超尺寸限法定尺寸）

## 13. Load Signage, Flags & Lighting（标识旗帜灯光）

- 灯：琥珀/红爆闪/strobe，500 英尺/360° 可见，货物前后
- 牌："OVERSIZE LOAD"，7'×18"，字 10"，黑字黄底，组合车前后
- 旗：18"×18" 红方旗，货物四角
