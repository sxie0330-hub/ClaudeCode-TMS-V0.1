# California — Oversize/Overweight Permit Regulations

采集：oversizeloadassistant.com（Super Search Engine，会员），2026-10-15。
提醒：网站为资料整理库，实际出车前请以 Caltrans 官方最新规定为准。

## 0. 基本信息（General Information）

- 主管机构：CALTRANS, Transportation Permits Section
- 地址：1120 N Street, Sacramento, CA 95814
- 电话：916-322-1297 / 传真：916-322-4966
- 许可有效期：7 天；办公时间：8:00am–5:00pm（太平洋时间）

## 1. Legal Dimensions & Weights（法定尺寸重量）

| 项目 | 标准 |
|---|---|
| 法定宽 | 8'6" |
| 法定高 | 14'0" |
| 法定长 | 65'0"（CA）；STAA 不限 |
| 前悬 | 3'0" |
| 后悬 | 2/3 轴距（从第 2 轴中心到最后轴中心量） |
| 挂车长 | 48/53（STAA，见注 2） |
| Kingpin | 不限 / 40'0"（STAA，见注 2） |
| 总重 | 80,000 磅 |
| 单轴 | 20,000 磅 |
| 双轴 | 34,000 磅 |
| 三轴 | 见注 3 |
| 四轴 | 不合法 |

- 注 2（STAA）：挂车 ≤48'0" kingpin 不限；48'–53'0" kingpin 最长 40'0"；>53' 除非货物需要否则不批；CA 法定 65'0" 长、kingpin 最长 40'0"；kingpin 从其中心量到挂车最后轴中心。
- 注 3（三轴）：轴间距 8'0"–8'11" = 34,000 磅；9'0"–9'11" = 42,500 磅；10'0"+ = 43,500 磅。
- 长度豁免：电杆、木材、管材、一体结构件等无固定长度限制。

## 2. Overweight Allowances（超重许可上限）

- 单轴：20,000 磅（有检验报告可到 22,000）
- 双轴/三轴：见重量表；四轴：不合法
- 总重上限：250,000 磅；超过需结构审查，审批最多 30 个工作日
- 注册总重：80,000 磅
- 16 轮 trunnion 轴组：每组最多 60,000 磅

## 3. Permit Fees（许可费用）

| 项目 | 费用 |
|---|---|
| 单次许可（法定重量） | $16.00 |
| 单次许可（超重） | $16.00 |
| Superload | $16.00 + 审核 $50.00/小时；最低收费 $66.00 |
| Mileage fee | N/A |
| 年票（Annual） | $90.00 |
| Repetitive 单次票 | $90.00 |

## 4. Annuals（年票）

- 宽 12'0"：CA 法定年票、STAA 年票均可，含 Legal / Green / Purple 重量档；STAA 年票路线受限
- 宽 12'0" 活动房：法定重量
- 长度：空载多轴 110'0"（需 CA 检验报告）；125'0"（检验报告注明可转向）；活动房 105'0"（含牵引杆的 housing 80'0"）
- 自行式车辆：有检验报告可办年票；拖车（wrecker）拖故障车可办年票
- Repetitive 90 天票：同一货物同一路线可重复申请，州逐案审批

## 5. Curfews（限行）

- 有 curfew；分城市地图：Los Angeles、Sacramento、San Diego、San Francisco（网站提供各城市 curfew 地图链接）

## 6. Drop/Lift Axles（升降轴）

- 超重时是否必须放下：否
- 需有效检验报告的情形：4 轴牵引车带升降轴；其他带升降/翻转轴且共用悬挂、重量分配 ±10% 内、或车外可控制的设备

## 7. Pilot Car Requirements（护送车要求）

| 触发条件 | 标准 |
|---|---|
| 宽 | 12'0" 起（见注 1） |
| 长 | 120'0" 起（见注 1） |
| 高 | >17'0" |
| 悬 | >25'0" |

- 注 1：详见 Pilot Car Maps（路线分级决定）

## 8. Pilot Car Equipment & Certification（护送车设备）

- 认证：不需要
- 灯：琥珀色爆闪灯，360° 可见
- 牌："OVERSIZE" 或 "OVERSIZE LOAD"，离地至少 48"，面积 ≥440 平方英寸，字 6"×1" 笔画，黑字黄底；车身两侧须印公司名、城市、电话
- 旗：红/荧光橙 18" 方布，左右两侧
- 车辆：车宽至少 60"
- 其他设备：STOP/SLOW 牌、橙色背心、24" 红色应急旗、双向通讯设备

## 9. Police Dimensions（警车开道触发尺寸）

| 项目 | 标准 |
|---|---|
| 宽 | 16'0"（Yellow 4 车道路线 >16'0"；Green/Blue/Brown 2 车道 >15'0"） |
| 高 | 17'0"（>17'0" 若不压中线可豁免） |
| 长 | 185'0"（Yellow/Green >185'0"；Blue/Brown >135'0"；借用对向车道或压中线时必须） |
| 重量 | 州决定（如许可要求降速、桥上走中线，或州认为必要；借用对向车道时必须） |

- Red Route：警车尺寸要求另见 Red Route 链接和 Pilot Car Table
- 警车联系方式：随路线批复由 CA 提供（网站有 CHP 分区电话地图）

## 10. Superload Dims（特大件标准）

| 项目 | 标准 |
|---|---|
| 宽 | >16'0" |
| 高 | >17'0" |
| 长 | >135'0" |
| 悬 | 超过 2/3 轴距 |
| 总重 | >250,000 磅 |
| 单轴 | 22,000 磅 |

- Variance 许可：高 >17'0"；宽在 Green/Blue/Brown 路线 >15'0"、Yellow 路线 >16'0"；审批最多 30 天
- >250,000 磅需结构审查，最多 30 个工作日

## 11. Survey（路线勘测）

- 触发：宽 ≥22'0"；高 >17'0"；长 >135'0"（Variance 部门可能要求）、>185'0"（所有货物必须）；重量仅结构要求时
- 净空：货物与架空障碍物之间需 3" 间隙；高 >18'0" 可能需电力 clearance
- Survey 有效期：申请日起 30 天
- 要求：按路线+里程桩标出所有冲突点（架空线、信号灯、树枝等），说明每个冲突点的处理方案（含借用上下匝道绕行），列出可供让行的安全区域；申请公司负责自行联系沿线电力、信号灯、铁路方，许可办公室可能要求提供通知/批准证明（传真/邮件/书面）

## 12. Night & Weekends（夜间/周末）

- 周末（六/日）：可走（具体时间见 24/7 链接）；非 superload 在 4 车道高速上一般允许；重量 <250,000 磅
- 夜间：可走；非 superload 在 4 车道高速上一般允许；重量 <250,000 磅

## 13. Load Signage, Flags & Lighting（标识旗帜灯光）

- 灯（夜间）：侧悬 ≥12" 且车长 <120'0"——前后 steady 琥珀灯，300 英尺可见；车长 ≥120'0"——前后红色灯 300 英尺可见；尾悬 >3'0"——悬端 steady 红灯 300 英尺可见
- 牌：必须；"OVERSIZE LOAD"，12"×72"，2" 笔画，黑字黄底，车头车尾各一
- 旗：非夜间行驶必须；18"×18" 红或荧光橙

## 18. IRP/IFTA/DOT

- IRP/IFTA re-entry permit：需要；Hunter's permit：无；DOT number：不需要
