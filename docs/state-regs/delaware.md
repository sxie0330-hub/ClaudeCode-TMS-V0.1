# Delaware — Oversize/Overweight Permit Regulations

采集：oversizeloadassistant.com（Super Search Engine，会员），2026-10-16。
提醒：网站为资料整理库，实际出车前请以 Delaware DOT 官方最新规定为准。

## 0. 基本信息（General Information）

- 主管机构：DelDOT, P.O. Box 7065, Dover, DE 19903
- 电话：302-744-2700（列表显示 324-744-2700，疑为 302 笔误）/ 状态查询：302-744-2700
- 邮箱：haulpermit@delaware.gov（传真只走邮件）
- 许可有效期：5 天；办公时间：8:00am–4:00pm（东部时间）

## 1. Legal Dimensions & Weights（法定尺寸重量）

| 项目 | 标准 |
|---|---|
| 法定宽 | 8'6" |
| 法定高 | 13'6" |
| 法定长 | 见注 1 |
| 前悬 | 3'0" |
| 后悬 | 6'0" |
| 挂车长 | 53'0" |
| 总重 | 80,000 磅 |
| 单轴 | 20,000 磅 |
| 双轴 | 34,000 磅 |

- 注 1（长度）：单车 40'0"；州际/美道半挂 53'0"；其他道路 60'0"
- 豁免：农机（耕作时走州道）

## 2. Overweight Allowances（超重许可上限）

- 单轴：20,000 磅；双轴：40,000（超需工程审查）；三轴：60,000（超需工程审查）；四轴：80,000
- 总重：无固定上限；注册总重 80,000 磅
- 桥梁管理审查：单轴 >25,000 磅（或更低，许可办公室定）

## 3. Permit Fees（许可费用）

| 项目 | 费用 |

| 超重单次 | $30.00 + 每超 8,000 磅 +$10.00 |
| Superload | $60.00 + 每 8,000 磅 +$10.00 |
| 修改费 | $10.00 |
| 多趟许可 | $30.00 |
| 海运柜 | $30.00 + 每超 8,000 磅 +$10.00 |
| 收费高速费 | $11.00 |

## 4. Annuals（年票）

- 无年票

## 5. Curfews（限行）

- 无 curfew

## 6. Drop/Lift Axles（升降轴）

- 超重时必须放下：否（按轴重/轴间距/桥梁定）

## 7. Pilot Car Requirements（护送车要求）

- 宽 >13'0"：2 车道 1 前、4 车道 1 后；宽 >14'0"：2 辆；宽 >15'0"：2 辆 + 1 州警
- 高 ≥15'0"：2 辆；高 ≥17'6"：2 辆 + 1 州警
- 长 ≥90'0"：1 后；长 ≥100'0"：1 前 1 后；长 ≥120'0"：2 辆 + 1 州警
- 悬 ≥15'0"：1 后；重 >120,000 磅：2 辆

## 8. Pilot Car Equipment & Certification（护送车设备）

- 认证：不需要
- 灯：行驶全程开近光灯；灯排规格详细（43"–52" 长、10"–13" 宽、4"–8" 高，≥4 灯，1000 英尺/360° 可见，琥珀罩）
- 牌："OVERSIZE LOAD"，5'×12"，字 8"，黑字黄底，车顶牌双面字，前后牌单面
- 其他：双向电台

## 9. Police Dimensions（警车开道）

- 宽 >15'0"；高 ≥17'6"；长 ≥120'0"
- 州警电话：302-672-5460；传真：302-739-2869

## 10. Superload Dims（特大件标准）

- 宽 ≥15'0"；高 ≥15'0"；长 ≥120'0"；总重 >119,000 磅
- 单轴 20,000；双轴 40,000；三轴 60,000；四轴 80,000
- 逐案审；双轴 >40,000/三轴 >60,000 需工程审查；单轴 >25,000 需桥梁审查

## 11. Survey（路线勘测）

- 触发：高 15'0"（高 ≥14'6" 许可部门可要求）
- 净空：3"；有效期 14 天
- 高 ≥15'0"：DOT 信号主管须审批准，承运人须联系各县信号主管（Kent/Sussex 302-739-4366、New Castle 302-326-4589）
- 要求与加州类似（按路线+里程桩标冲突点、处理方案；申请公司负责联系电力/信号灯/线缆/私有业主并书面同意；需要时须雇 DelDOT 信号承包商铲斗车随行）

## 12. Night & Weekends（夜间/周末）

- 周末（日出–日落）：宽/高/长/重/悬不限；杆/桩 24/7 可走
- 夜间：须申请（许可 special provisions 注明）；限 长 ≤75'0"、宽 ≤12'0"、高 ≤14'6"、重 ≤120,000 磅，21:00–5:00

## 13. Load Signage, Flags & Lighting（标识旗帜灯光）

- 灯：琥珀/红常亮灯，500 英尺/360° 可见，货物前后
- 牌："OVERSIZE LOAD"/"WIDE LOAD"/"LONG LOAD"，7'×18"，字 10"，黑字黄底，车头+货物尾部
- 旗：18"×18" 荧光橙/红方旗，带杆，货物四角
