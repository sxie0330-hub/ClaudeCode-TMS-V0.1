# OOG 初筛（询报价页）

询价详情页的“OOG 初筛（按州）”按每个运输段、每辆车计算，代码在 `core/oog.py`。

## 资料来源
- **州规定**：`docs/state-regs/<州>.md` 是公司整理的 48 州资料（oversizeloadassistant.com，2026-10），
  整理成 `core/data/state_regs.json`（法定尺寸重量、超重许可上限、护送车 / 警车门槛、Superload、路线勘察、夜间周末限制）。
  一个规定有条件时（州际 / 非州际、指定道路等），数字取普通州道上最严的，原文条件写在 notes 里。
  8'6" 宽在 National Network 上各州都合法（23 CFR 658），所以宽度按不低于 8'6" 判断。
- **车型**：“车型库”（`/data/trailer/`，管理层可改），初始数据来自 `core/data/trailer_specs.json`（厂家 / 经销商规格表，含来源链接）。
  资料不全的车型默认不参与自动建议。车头自重默认 17,000 lbs（DOE 典型 Class 8），重载车头 25,000 lbs。请按实际合作车队修改。

## 怎么算
- 路线州 = 起点州 + 途经州 + 终点州（运输段里填；没填从地址里认州代码；都没有就按 8'6" / 13'6" / 80,000 lbs 常见上限）。
- 每车货物 = 件数平均分到车次；尺寸取最大的一件。
- 装车后高 = 货高 + 板高；宽 = max(货宽, 板宽)；后悬 = 货长 − 可装长度；整车长 = 挂车总长 + 车头约 20 ft + 后悬。
- **总重 = 货重 + 车头自重 + 挂车自重**（许可证看的是总重和轴重，不是货重）。
- 超尺寸 / 超重许可只发给**不可拆分**货物；货物标了“可拆分”又超限，会提示要拆分或多车。
- 轴数估算：（总重 − 转向轴 12,000）÷（轴数 − 1）与各州超重许可的串联轴每轴重量比较。只是估算，不是轴距 / 桥梁公式计算。
- 车型自动挑选：先找完全合法的最普通车型；再找高度合法、轴数够的；再找装车后最低的；车型库都装不下时提示要液压轴线车 / 桥式等专门车型。

## 公司规则：重型 20' BESS（2026-10）
货物名称含 BESS / ESS / battery / energy storage / Megapack / 储能 / 电池，长度 ≤ 21 ft，每车货重 ≥ 90,000 lbs 时：
- 路线经过 CA：一律用 9 轴（三轴车头 + 2 轴 jeep + 2 轴 RGN + 2 轴 booster，车型库 `rgn_9axle_team`）。
- 不经过 CA：用 4+4 共 8 轴（`axle8_4x4`），前提是平均每轴重量不超过沿途各州的超重许可每轴（串联轴 ÷ 2）；超过就改用 9 轴。
- 两套组合空车也要 permit。车型库里缺自重时照样按规则推荐，但会提示总重和轴重没法核。
- 运输段里手动指定了车型时，以指定的为准。

## 没做的
轴组重量和桥梁公式（要轴距）、路线净空 / 桥梁限重、各州具体路线限制。最终以各州 DOT 许可证为准。
