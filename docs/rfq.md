# 询报价（Leads → 报价 → 成单）

取代 Monday.com 的询价看板：客户询价进来 → 整理需求 → 向承运商询价 → 给客户报价 → 成单后一键转成项目交给操作。

**TMS 不会替任何人发邮件。** 所有给承运商和客户的邮件都只是草稿：复制，或者点“在 Gmail 打开”，由人核对后自己点发送。

## 谁能用
- 管理层、操作 OP、新角色 **询报价 / 销售（RFQ）**。在“团队”页给询报价同事分配这个角色。
- 询报价阶段的成本价，这三种角色都能看到。应收 AR、应付 AP 角色看不到询报价。
- RFQ 角色可以查看运输数据，但不能修改。

## 流程

1. **新询价**（询报价 → 新询价）：
   - 粘贴客户的邮件或微信内容，也可以上传 PDF、截图、Excel，AI 会整理成一条询价：
     - 客户和联系人；
     - 每段运输：起点 → 终点、服务、车型、车次、日期；
     - 货物：件数、尺寸和重量，统一换算成 ft / lbs；
     - 还要问客户哪些问题。
   - 整理完直接建好询价，所有内容都能改。也可以手动新建。
   - 微信没有接口可以直接读取，复制文字或截图上传即可。
2. **需求 Scope of Work**：
   - 运输段和货物都可以增、删、改；尺寸和重量可以填任何单位。
   - 每件货物自动做 **OOG 初筛**：超宽 / 超高 / 超长 / 超重提示，以及建议车型（Flatbed / Step Deck / RGN / 多轴）。
   - 初筛只按常见上限判断，以许可证办理结果为准。
3. **找车询价**：
   - 生成英文询价邮件。尺寸按承运商习惯写成 13'6" 这样的格式，**不含客户名称**。
   - 勾选承运商后，每家都有“在 Gmail 打开”，收件人已填好。
   - 发完后点“记录为已询价”。超过 2 天没回价的会出现在今日待办。
4. **承运商回价**：
   - 把回复或报价单 PDF 贴进来，AI 逐项列出金额：运费、燃油、许可证、护送，以及视情况才发生的 Detention 等。
   - 核对后保存。之前“已询价”的那一行会更新，不会重复。也可以手动录入。
   - 每段可以“选用”一家。没有选用时，按最便宜的计算。
5. **给客户报价**：
   - 按成本加价（默认 15%，金额向上取整到 $5）生成新版本，逐行可改，页面上会显示售价、成本、毛利。
   - 生成英文邮件草稿和 PDF 报价单，PDF 有两种样式：
     - **简式**：一张价格表，加上前提和条款；
     - **正式**：服务范围、按分段列价格和小计、视情况发生的费用、前提和不含项、条款、双方签字栏。大项目可以用“分段标题”按阶段或线路分组。
   - 更复杂的报价（比如需要附图纸、方案说明）：把 PDF 下载下来，和其他文件一起作为附件发给客户。
   - 发出后，把报价状态改成“已发客户”。
6. **成单**：
   - 选择交给哪位操作、用哪份客户报价、每段用哪家承运商，一键建立：
     - 项目，以及每车一个 Load；
     - 货物明细；
     - 运输段：承运商和计划日期，OOG 货物会标注需要许可证；
     - 应付（来自承运商报价）和应收（来自客户报价）。
   - 新客户和新地址会自动建立。“视情况发生”的费用不会自动录入。
   - 没成单的记下原因。

## 今日待办
- 你负责的询价，报价截止日是今天、明天或已经过了。
- 承运商询价超过 2 天没回复。
